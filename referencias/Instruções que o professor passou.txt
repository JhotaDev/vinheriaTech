Desenvolvimento de Aplicação de Supervisão para IoT
Objetivo: Criar um software de supervisão que monitore em tempo real os dados de temperatura, umidade e luminosidade coletados por um dispositivo ESP32, utilizando a API do FIWARE.
Especificações:
	• Linguagem de Programação: A escolha da linguagem de programação fica a critério do desenvolvedor.
	• Fonte de Dados: O ESP32 deverá enviar os dados de temperatura, umidade e luminosidade para a aplicação via API do FIWARE.
	• Short-Term History: Os dados deverão ser armazenados de forma histórica no MongoDB e acessado via API do STH-Comet.
	• Alertas: Implementar um sistema de triggers que, ao detectar valores fora dos limites normais, envie um comando para o ESP32 para ativar um LED azul como sinal de alerta. O LED deve piscar para indicar uma condição anormal.
	• Comportamento do LED: O LED azul deve permanecer desligado caso os valores estejam dentro dos parâmetros considerados normais.
	• Sensores: DHT 11 e LDR.
Este projeto visa garantir uma supervisão eficaz e em tempo real das condições ambientais, permitindo uma resposta rápida a qualquer desvio através de alertas visuais.
